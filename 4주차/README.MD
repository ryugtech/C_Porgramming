4주차 C언어 프로그래밍 실습

함수를 만들어두면 동일한 코드를 여러 번 작성하지 않고 재사용할 수 있으며, 유지•보수가 용이하다
함수는 매개변수를 통해 데이터를 전달받고, 결괏값을 반환한다

rand() 함수를 호출하기 전 srand(time(NULL))을 사용하면 난수가 균등하게 분포된다

전역변수는 자동으로 초기화된다

static 지정자로 정적 변수를 선언하면 메모리에 할당되어, 프로그램 종료까지 유지된다

가변 매개변수로 매개변수의 개수를 정해두지 않고 사용할 수 있다
int sum(int num, ...) // ...으로 가변 매개변수 시작

va_list args // 가변 매개변수 목록 저장

va_start(args, num) // 가변 매개변수 목록 초기화

va_arg(args, int) // 다음 int 인자 가져오기

va_end //목록 정리
